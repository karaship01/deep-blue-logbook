# Deep Blue - Dalış Günlüğü 🌊

Bu proje, Flask Mega-Tutorial temel alınarak geliştirilmiş kapsamlı bir dalış günlüğü web uygulamasıdır. 

## Mevcut Özellikler
* Kullanıcı Kayıt ve Giriş Sistemi (Authentication)
* JWT Destekli Güvenli Şifre Sıfırlama
* Asenkron E-posta Gönderimi (Flask-Mail & Threading)
* Dinamik Veritabanı Yönetimi (SQLAlchemy)
